## Release decision from the inspected snapshot

1. No macOS packaging pipeline or installable artifact.
2. No signing, notarization, clean-Mac, or update evidence.
3. Importers are not integrated through file picker → preview → transactional persistence → renderer.
4. Current importer compatibility relies on synthetic fixtures, not sanitized current exports.
5. Shared SQLite/memory code is not exposed through the production Electron bridge; current chats remain renderer storage based.
6. No true packaged-app quit/relaunch persistence test.
7. No backup/restore or release rollback path.
8. No current dependency audit, SBOM, complete license review, or accessibility audit.
